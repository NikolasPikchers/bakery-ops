# Корректировки ФОТ

На странице `/fot` клик по дню открывает редактор выхода на смену и доплаты / удержания.
Клик по 1-й или 2-й выплате открывает редактор отдельной поправки к этой выплате.
Клик по имени сотрудника открывает переименование (до 100 символов).
Новое имя используется во всех месяцах и на странице сотрудников. ID, смены, ставка
и корректировки сохраняются. Одинаковые имена в одной группе требуют уточнения фамилией.
Повторный запуск `scripts/seed-employees.mts` пропускает уже заполненную БД, чтобы
не создавать заново переименованных сотрудников под прежними именами.

- `+200` добавляет 200 ₽, `-200` удерживает 200 ₽. Поддерживаются копейки, точка и запятая.
- В поле хранится итоговая корректировка, а не очередная операция. Кнопки ±200 меняют это значение.
  Повторное сохранение или повтор HTTP-запроса не удваивает сумму.
- `0` удаляет корректировку. Комментарий необязателен, до 300 символов.
- Доплата за день учитывается и в выходной. Снятие смены её не удаляет.
- Дневные поправки входят в свою календарную половину месяца без сдвига премий.
  Правило переноса премии за последнюю смену остаётся прежним.
- Прямая поправка выплаты прибавляется отдельно. В расходах дашборда она учитывается
  в дату этой выплаты; если смен нет — 15-го или в последний день месяца.
  Дневная поправка учитывается в свой день. Будущие суммы не входят в дашборд «по сегодня».
- В календаре и выплатах сотрудников поправки видны отдельно от премии от выручки.
  Дневная поправка за отработанную смену влияет на среднюю ЗП, но не на среднюю премию.
- Менять данные может только владелец. Сотрудники имеют доступ только к просмотру.

## Обновление БД

Перед выкладкой обновлённого приложения применить `prisma/fot-adjustments.sql` к его БД.
Скрипт идемпотентный и добавляет только две таблицы; старый код продолжает работать.
В новой локальной БД достаточно обычного `prisma db push`.

Проверки:

```sh
npm test
npx tsc --noEmit
npx eslint src
npx prisma validate
# FOT_TEST_DATABASE_URL должен указывать на отдельную тестовую PostgreSQL.
npx vitest run src/lib/db/fot-adjustments.integration.test.ts
```
