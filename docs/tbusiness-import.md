# Импорт расходов из выписки Т-Бизнес

T-Bank блокирует иностранные IP, а Mac Mini выходит в интернет через зарубежный VPN —
поэтому API не используем. Вместо этого импортируем **файл выписки** по счёту.
Выручка сюда НЕ попадает (она из iiko); из выписки берём только **расходы** (исходящие операции).
Все импортированные расходы → **Плюшкино (point-1)** (разнесение по точкам — отдельная задача).

## Как обновить расходы

1. С устройства, которое видит ЛК Т-Бизнес (телефон/ноут на росс. сети), выгрузи **выписку по счёту**
   за нужный период. Формат — CSV (банк отдаёт `.zip` с `.csv` внутри; подойдёт и распакованный `.csv`).
2. Перенеси файл на Mac Mini (Телеграм-бот / AirDrop / `~/Downloads`).
3. Предпросмотр без записи в БД (увидеть разбивку по категориям):
   ```
   cd ~/bakery-ops
   npm run import:statement -- "/путь/к/Выписка.zip" --dry
   ```
4. Импорт:
   ```
   npm run import:statement -- "/путь/к/Выписка.zip"
   ```
   Вывод: `{ fetched, outgoing, imported, updated }`. Идемпотентно — повторный импорт того же
   периода ничего не дублирует (дедуп по `externalId = счёт|номер платежа|дата|сумма`),
   а изменения суммы/назначения подтянет.

## Категоризация

Логика в `src/lib/tbank/categorize.ts`:
- **Исключаются** переводы себе на счёт (вывод средств ИП): `OWNER_INNS` + назначение «перевод собственных средств».
- **Продукты**: покупки по бизнес-карте («Отражение операции оплаты по карте …») + ИНН поставщиков из `CATEGORY_BY_INN`.
- **Аренда / Налоги / ФОТ / Коммуналка**: по ключевым словам (`RULES`) и ИНН.
- Банковские/эквайринговые комиссии → **Прочее**.
- Остальное → **Прочее** с пометкой needsReview (кандидаты на ручную докатегоризацию).

### Как уточнить категории
- Новый поставщик продуктов / арендодатель → добавить его **ИНН** в `CATEGORY_BY_INN`.
- Новое ключевое слово → в соответствующий `RULES`.
- После правок повторить импорт (идемпотентно перезапишет категории).

## Заметки
- ФОТ (зарплаты) через этот счёт не проходят — выплачиваются налом из переводов себе. При появлении
  безналичных выплат зарплаты добавить правило/ИНН.
- Чтобы дашборд показывал чистую прибыль, нужна выручка из iiko (вносится отдельно).
